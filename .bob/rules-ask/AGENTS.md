# AGENTS.md — Ask Mode

## Non-Obvious Context for Answering Questions

- The `edu.java.Sysout` logger name is a deliberate convention (not a typo) — it identifies the one safe path to stdout in the uber-jar; all human-facing output goes through it
- `config.properties` does not exist in the repo (gitignored) — questions about missing config should direct to `config.properties.example`
- `dependency-reduced-pom.xml` at the project root is auto-generated by the shade plugin — never edit it manually
- `OPENAI_REASONING_MODEL` falls back to `OPENAI_MODEL` if unset — it is not a required key; the reasoning test is conditionally skipped when blank, not when absent
- TTS, STT, image generation, and moderation examples only work against OpenAI cloud (not local servers) — this is by design, not a bug
- `VisionExample.toBase64DataUrl()` is `static` and re-usable from tests — the integration test already calls it
- `JavaOpenAI.JAVAOPENAI_VERSION` is a plain string constant; it is not substituted from `pom.xml` at build time
- JUnit `6.1.3` is correct — JUnit released a real 6.x major in 2024/2025; do not suggest downgrading
- The `.bob/` directory is Bob AI assistant configuration — not part of the Java project
